# DoxRain Cherokee 1.0.0 — Учебник (русский)

## Релиз

DoxRain Cherokee 1.0.0 — первая основа языка DoxRain, ориентированная на Windows. Целевые системы: Windows 7 и более новые версии Windows; предусмотрены сборки x86 и x64 с MSVC. Поддержка Linux запланирована на будущее.

Основные направления: сначала разработка 2D, затем 3D/AAA, защитные инструменты кибербезопасности, внешнее и встроенное программирование. Сначала используется интерпретатор; байткод и нативная компиляция планируются позже.

В релиз пока не добавлены готовые ZIP-архивы. Это фундаментальная версия для разработки, а не готовый производственный фреймворк.

## Исходный код

Чистый прототип Rust (`doxrain_fullcode_Prototype.rs`) содержит лексер, парсер, AST, окружение, интерпретатор, менеджер пакетов и экспериментальное направление компилятора/виртуальной машины. Ветка Cherokee описывает Windows-хост и архитектуру фреймворка.

## Синтаксис

```dox
let name = "DoxRain"
let answer = 40 + 2
show "Hello, {name}!"
show answer
```

Поддерживаются целые и дробные числа, логические значения, строки, списки и `Void`. Операторы: `+`, `-`, `*`, `/`, `%`, `==`, `!=`, `<`, `>`, `<=`, `>=`.

```dox
if answer >= 42 {
    show "Правильно"
} else {
    show "Попробуйте ещё раз"
}

for i in 0..3 {
    show "Элемент {i}"
}
```

Функции объявляются через `fn`. Области видимости реализованы, но возврат значений и интеграция функций ещё развиваются.

```dox
fn greet(user) {
    show "Добро пожаловать, {user}"
}

greet("Rain")
```

## Пакеты

```dox
pkg list
pkg install scene
use scene
pkg remove scene
```

Текущий менеджер пакетов является прототипом. В будущем Cherokee будет устанавливать пакеты для пользователя после проверки совместимости, контрольной суммы и подписи.

## Сборка

```bat
cargo build --release --target x86_64-pc-windows-msvc
cargo build --release --target i686-pc-windows-msvc
```

Перед заявлением совместимости нужно проверить Windows 7 SP1, Windows 10 и Windows 11.

## Ограничения

Это ещё не полноценный компилятор, игровой движок, набор средств безопасности или embedded-toolchain. Нужны тесты, диагностика, стабильный CLI и проверка VM. Инструменты безопасности должны использоваться только для защиты и с разрешением владельца системы.
