# DoxRain Cherokee 1.0.0 — Навчальний посібник (український переклад)

## Реліз

DoxRain Cherokee 1.0.0 — перша Windows-орієнтована основа мови DoxRain. Цільові системи: Windows 7 і новіші версії Windows; заплановано збірки x86 та x64 з MSVC. Підтримку Linux планують у майбутньому.

Напрями: спочатку розробка 2D, потім 3D/AAA, захисні інструменти кібербезпеки, зовнішнє та вбудоване програмування. Першим рушієм є інтерпретатор; байткод і нативна компіляція заплановані пізніше.

Готові ZIP-архіви поки не додані до релізу. Це базовий реліз для розробки, а не завершений промисловий фреймворк.

## Код і синтаксис

Прототип Rust `doxrain_fullcode_Prototype.rs` містить лексер, парсер, AST, середовище виконання, інтерпретатор, менеджер пакетів і експериментальний компілятор/VM. Cherokee описує Windows-хост і структуру фреймворку.

```dox
let name = "DoxRain"
let answer = 40 + 2
show "Hello, {name}!"

if answer >= 42 {
    show "Правильно"
} else {
    show "Спробуйте ще раз"
}

for i in 0..3 {
    show "Елемент {i}"
}
```

Підтримуються числа, логічні значення, рядки, списки та `Void`; оператори: `+`, `-`, `*`, `/`, `%`, `==`, `!=`, `<`, `>`, `<=`, `>=`.

```dox
fn greet(user) {
    show "Вітаємо, {user}"
}

greet("Rain")
```

## Пакети та збірка

```dox
pkg list
pkg install scene
use scene
pkg remove scene
```

```bat
cargo build --release --target x86_64-pc-windows-msvc
cargo build --release --target i686-pc-windows-msvc
```

Потрібно перевірити Windows 7 SP1, Windows 10 і Windows 11. Підтримка Linux не входить до першої версії.

## Обмеження

Мова, компілятор, Cherokee, updater і доменні API все ще розробляються. Інструменти кібербезпеки слід використовувати лише законно, для захисту та з дозволу власника системи.
