# DoxRain Cherokee 1.0.0 — دليل تعليمي (العربية)

## الإصدار

DoxRain Cherokee 1.0.0 هو أول أساس للغة DoxRain موجه أولاً إلى Windows. يستهدف Windows 7 والإصدارات الأحدث، مع إنشاءات MSVC بمعمارية x86 وx64. دعم Linux مخطط له في المستقبل.

يبدأ المشروع بتطوير ثنائي الأبعاد، ثم يتجه إلى ثلاثي الأبعاد وAAA، وأدوات الأمن السيبراني الدفاعية، والبرمجة الخارجية والمدمجة. المفسر هو محرك التنفيذ الأول؛ أما bytecode والترجمة الأصلية فمخططان لاحقاً.

لا توجد ملفات ZIP مترجمة مرفقة بالإصدار حتى الآن. لذلك فهذا إصدار تأسيسي للتطوير وليس إطار عمل إنتاجياً مكتملًا.

## الكود وبنية اللغة

يحتوي النموذج الأولي المكتوب بـ Rust، وهو `doxrain_fullcode_Prototype.rs`، على lexer وparser وAST وبيئة تشغيل ومفسر ومدير حزم، إضافة إلى اتجاه تجريبي للمترجم والآلة الافتراضية. يحدد Cherokee مضيف Windows وبنية الإطار.

```dox
let name = "DoxRain"
let answer = 40 + 2
show "Hello, {name}!"
show answer

if answer >= 42 {
    show "صحيح"
} else {
    show "حاول مرة أخرى"
}

for i in 0..3 {
    show "العنصر {i}"
}
```

تدعم اللغة الأرقام والقيم المنطقية والنصوص والقوائم و`Void`. ومن العمليات: `+` و`-` و`*` و`/` و`%` و`==` و`!=` و`<` و`>` و`<=` و`>=`.

```dox
fn greet(user) {
    show "مرحباً، {user}"
}

greet("Rain")
```

## الحزم والبناء

```dox
pkg list
pkg install scene
use scene
pkg remove scene
```

```bat
cargo build --release --target x86_64-pc-windows-msvc
cargo build --release --target i686-pc-windows-msvc
```

يجب اختبار Windows 7 SP1 وWindows 10 وWindows 11 قبل إعلان التوافق. لا يتضمن الإصدار الأول دعم Linux.

## القيود

اللغة والمترجم وCherokee والمحدّث وواجهات المجالات المتخصصة ما زالت قيد التطوير. يجب استخدام أدوات الأمن السيبراني لأغراض دفاعية وقانونية وبإذن مالك النظام.
